Investigation Brief

SECT. 01THE PROBLEM
THE THESIS
THE ARTIFACT

The Problem

Generative agents confidently fabricate. They quote sources that don't exist, invent statistics, and synthesize plausible prose from thin evidence. In research tasks, that's disqualifying.

The Thesis

Grounding is architectural, not cosmetic. Every sentence must bind to a retrieved chunk. Every chunk must carry provenance. Every claim must survive a re-retrieval check.

The Artifact

Submit an entity name — person or company. Receive a cited dossier with inline source links, a verifier-pruned draft, and a demonstrable adversarial defense layer.

§ Executive
Summary

Dossier is a capstone submission for a 14-day solo build. The operating system underneath is deliberately over-engineered for its scale: a stateful LangGraph supervisor, a fleet of FastMCP servers, an injection classifier acting on every retrieved chunk, and a verifier that breaks the writer's draft into atomic claims and re-grounds each one against the per-investigation vector index.

The choice of entity type is load-bearing for the demo. Corporate subjects route through a bespoke SEC EDGAR MCP with Item-level chunking; individuals route through CourtListener. Both paths converge on the same retrieval index — the same verifier — the same evaluator — producing citation-accurate output measurable against a hand-labelled gold set.

The system covers all 29 bootcamp concepts. None are decorative; five are the load-bearing core that separates this from a wrapper around a chat API.

SECT. 04SENIOR-SIGNAL FEATURES
LOAD-BEARING COMPONENTS
DO NOT CUT

Verifier Loop — the core invariant

Day 7 · Atomic claim grounding · Hallucination reduction

The writer drafts. The verifier extracts every atomic claim from that draft, re-retrieves against the per-investigation index for each one, and scores supported / partial / unsupported. Anything unsupported is stripped or flagged inline. The hallucination problem is not prevented — it is caught.

CUT = NO PROJECT

Injection Defense

Day 6 · Sandboxed retrieval · Attempt log

Every retrieved chunk is delimited with sandbox tokens and passed through a small LLM-judge injection classifier before it reaches any reasoning model. Detected attempts are logged and surfaced in the UI. The demo's "Attack This Dossier" button runs the real path — no mocks.

ADVERSARIAL · IN-BAND

Evals Harness

Day 8 · Gold set · Trend chart · CI-gate

Ten hand-labelled entities. Three metrics: citation accuracy, hallucination rate, coverage. Automated runner with a live trend chart in the UI. Prompt or model changes that regress evals fail CI the way a broken test does.

MEASURED · NOT VIBES

Multi-Model Routing

Day 10 · Per-stage dispatch · Cost panel

Haiku for mechanical extraction, Sonnet for verification, Opus for synthesis. Live cost / latency / token panel per stage in the UI. The narrative: cheap models carry the volume, frontier models carry the judgment.

PRODUCTION THINKING

Per-Investigation RAG Index

Day 3 · Source-aware chunker · Citation registry

Each investigation gets its own Chroma collection — isolated, retention-bounded, deletable. Every chunk carries provenance (source type, accession, offset) that doubles as the citation lookup. The writer queries it; the verifier queries it; the UI's citation clicks resolve through it.
